Análisis de Datos Climáticos Globales

Descripción del Proyecto

Este proyecto fue desarrollado como parte del Trabajo Práctico de la materia Organización Empresarial de la Tecnicatura Universitaria en Programación (UTN).

El objetivo principal es aplicar herramientas de control de versiones, trabajo colaborativo y organización de proyectos mediante Git, GitHub y Jira, utilizando un caso práctico de análisis de datos climáticos globales.

El proyecto analiza registros históricos de temperatura global para generar estadísticas básicas y visualizaciones que permitan observar tendencias climáticas a lo largo del tiempo.
